## Rules

- Do not copy an LLs file and replace its copyright header.
- Do not describe the original developer as a sponsor, partner or endorser.
- Preserve the complete BSD disclaimer in the distributed project.
- For mixed-origin files, retain every applicable copyright notice.
- Prefer small, reviewable imports over wholesale copying.
